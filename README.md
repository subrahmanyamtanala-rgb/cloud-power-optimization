# Cloud Power Optimization Project

## Overview
This project focuses on optimizing cloud power usage through advanced machine learning techniques and optimization algorithms, particularly the Firefly algorithm. 

## Directories and Files Structure
- `firefly_algorithm/`
  - `firefly.py` : Implementation of Firefly algorithm.
- `vm_placement/`
  - `vm_placement.py` : Virtual Machine placement model based on optimization techniques.
- `data_structures/`
  - `data_structures.py` : Custom data structures used in the project.
- `README.md` : Project documentation explaining setup and usage.

## Prerequisites
- Python 3.8+
- Required libraries are listed in `requirements.txt`

## Installation
Clone the repository and install the dependencies:

```bash
git clone https://github.com/subrahmanyamtanala-rgb/cloud-power-optimization.git
cd cloud-power-optimization
pip install -r requirements.txt
```

## Usage
Run the VM placement model:
```bash
python vm_placement/vm_placement.py
```
